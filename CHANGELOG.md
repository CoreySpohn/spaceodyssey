## [0.2.0](https://github.com/CoreySpohn/spaceodyssey/compare/v0.1.0...v0.2.0) (2026-11-15)


### ⚠ BREAKING CHANGES

* **bracket:** the package policy replaces the rule-order policy and reads the ledger balance
* **bracket:** the verdict scores tracks against truth by identity; the outcome table keeps activity accounting
* **bracket:** arms are declared grants on the observer, decoded into a printed grants line
* **criteria:** add the criterion family, its state folded by the summary observer through the codec
* **jaxedith:** one measurement row with detection and band axes replaces the visit and block rows
* **jaxedith:** one observing source on a declared, named mode table; drop the first-summary block model
* **photomancy:** the first tier draws the declared population, dark slots carry an existence probability, and the class is a claim
* **photomancy:** planets are named parameter modules above the refit and the truth catalog is a packed module
* **bracket:** row capacities count declared visits and spectra and need a horizon
* **bracket:** remove the reveal plumbing, block probabilities and the policy's characterization state
* **skyscapes:** the truth keeps every planet up to its capacity and belief bounds come from a declared population
* **core:** policies and refits read a decision view that carries the planning model and withholds the world source
* **skyscapes:** truth carries an albedo per declared band and no constructor has a wavelength default
* **spaceodyssey:** remove the legacy certified-yield modules
